[*] [COLOR=#ffaa00][B]Scoreboard Memory Leak Prevention[/B][/COLOR]
[LIST]
[*] [B]Real-Time Scoreboard Scrubbing:[/B] Fixed a critical issue where dropped items and their glowing visual display entities left their UUIDs registered in the server's main scoreboard teams (`LG_WHITE`, `LG_GOLD`, etc.) after being picked up, despawning, or merging. This prevents severe memory accumulation (roughly 4,000 stale entries per hour) that eventually exceeded the 2 MB Netty packet limit and kicked joining players.
[*] [B]Sanitized Reloads & Startup:[/B] The configuration load/reload process now automatically sanitizes all LootGlow scoreboard teams, removing any stale registrations to prevent accumulated leftovers from saving permanently in `scoreboard.dat`.
[*] [B]Reload Map Sanitation:[/B] Added code to fully purge all remaining active item tracking collections (like grouped items, magnet animations, light sources, and bounce states) during configuration reloads, preventing lingering memory leaks.
[/LIST]
[*] [COLOR=#55ff55][B]World & Chunk Optimization[/B][/COLOR]
[LIST]
[*] [B]Chunk Unload Cleanup:[/B] Registered a chunk unload listener to immediately release visual tracking and clear scoreboard entries for any glowing items inside chunks that unload, preventing visual artifacts and leaks when players move between chunks.
[*] [B]Piston Harvest Integration:[/B] Registered listeners for block piston extension and retraction events to automatically remove crop indicators when harvested by piston mechanisms in automatic sugarcane, melon, or pumpkin farms, preventing orphaned floating visual indicators.
[/LIST]
[*] [COLOR=#aaaaff][B]Code Quality & Internal Cleanup[/B][/COLOR]
[LIST]
[*] [B]Dead Method Removal:[/B] Removed six obsolete private methods (`startMagnetTask`, `startBeamAnimationTask`, `startFarmingAnimationTask`, `startBouncingTask`, `startAspirationTask`, `startGlobalSyncTask`) that had been fully superseded by the unified `startUnifiedTickTask` system, reducing class bloat and eliminating "never used" IDE warnings.
[*] [B]Null-Safety Lambda Fixes:[/B] Replaced several `Entity::remove` method references inside `forEach` loops with explicit lambda expressions (`e -> e.remove()`) across both `LootGlow.java` and `ItemListener.java` to satisfy the compiler's strict `@Nonnull` contract and eliminate unchecked null-safety warnings.
[*] [B]Lambda Variable Conflict Fix:[/B] Resolved a variable shadowing conflict in `ItemListener.java` where a lambda parameter name clashed with a variable in the enclosing scope, preventing a compilation error.
[*] [B]Dead Variable Removal:[/B] Removed unused `originalYaw` and `originalPitch` local variables in the visual sync block of `LootGlow.java` — their values were captured but never read, as the yaw/pitch is already preserved through the `itemLoc.clone()` call.
[/LIST]
