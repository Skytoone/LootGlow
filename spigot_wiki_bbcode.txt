[SIZE=5][B][COLOR=#FFD700]📦  1. INSTALLATION[/COLOR][/B][/SIZE]
[COLOR=#888888]────────────────────────────────────────────────────[/COLOR]
[COLOR=#D3D3D3][LIST=1]
[*] Download the [B]LootGlow.jar[/B] file.
[*] Place it in your server's [I]/plugins/[/I] directory.
[*] Restart your server to generate configuration files.
[*] Customize [B]config.yml[/B] and [B]messages.yml[/B] to your liking.
[/LIST][/COLOR]

[SIZE=3] [/SIZE]

[SIZE=5][B][COLOR=#FFD700]⚙️  2. CONFIGURATION GUIDE[/COLOR][/B][/SIZE]
[COLOR=#888888]────────────────────────────────────────────────────[/COLOR]

[B][COLOR=#FFFFFF]General Settings:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]enabled:[/COLOR][/B] [COLOR=#AAAAAA]Globally enable or disable the entire plugin.[/COLOR]
[*] [B][COLOR=#FFD700]only-player-drops:[/COLOR][/B] [COLOR=#AAAAAA]If true, visuals only apply to items dropped by players (not mobs).[/COLOR]
[*] [B][COLOR=#FFD700]disabled-worlds:[/COLOR][/B] [COLOR=#AAAAAA]List of world names where the plugin is completely inactive.[/COLOR]
[*] [B][COLOR=#FFD700]despawn-time:[/COLOR][/B] [COLOR=#AAAAAA]Seconds before items despawn. Used for the hologram countdown timer (default 300).[/COLOR]
[*] [B][COLOR=#FFD700]default-glow:[/COLOR][/B] [COLOR=#AAAAAA]Fallback glow setting for items that don't match any category (default true).[/COLOR]
[*] [B][COLOR=#FFD700]check-updates:[/COLOR][/B] [COLOR=#AAAAAA]Automatically check for new versions on startup.[/COLOR]
[*] [B][COLOR=#FFD700]Portal Support:[/COLOR][/B] [COLOR=#AAAAAA]Visuals persist perfectly through Nether and End portals. No configuration needed.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Hologram Settings:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]holograms.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Toggle floating name labels above items.[/COLOR]
[*] [B][COLOR=#FFD700]holograms.height-offset:[/COLOR][/B] [COLOR=#AAAAAA]Vertical position of the hologram above the item (recommended 0.7).[/COLOR]
[*] [B][COLOR=#FFD700]holograms.see-through:[/COLOR][/B] [COLOR=#AAAAAA]If true, the hologram text is visible through blocks.[/COLOR]
[*] [B][COLOR=#FFD700]holograms.background:[/COLOR][/B] [COLOR=#AAAAAA]If true, adds a dark background panel behind the hologram text.[/COLOR]
[*] [B][COLOR=#FFD700]holograms.view-distance:[/COLOR][/B] [COLOR=#AAAAAA]Distance in blocks at which holograms become visible (default 15).[/COLOR]
[*] [B][COLOR=#FFD700]holograms.show-amount:[/COLOR][/B] [COLOR=#AAAAAA]Show the stack quantity on the label (e.g. x32).[/COLOR]
[*] [B][COLOR=#FFD700]holograms.show-timer:[/COLOR][/B] [COLOR=#AAAAAA]Show a live countdown before the item despawns.[/COLOR]
[*] [B][COLOR=#FFD700]holograms.timer-on-new-line:[/COLOR][/B] [COLOR=#AAAAAA]Display the timer on a separate line below the item name.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Dynamic Shadows:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]rpg-drops.shadows.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Adds a semi-transparent 3D shadow under ground items for depth and realism.[/COLOR]
[*] [B][COLOR=#FFD700]rpg-drops.shadows.scale:[/COLOR][/B] [COLOR=#AAAAAA]Size of the shadow relative to the item (default 0.4).[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]RPG Drops (Flat Item Rendering):[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]rpg-drops.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Lay items flat on the ground for an RPG-style look.[/COLOR]
[*] [B][COLOR=#FFD700]rpg-drops.enabled-categories:[/COLOR][/B] [COLOR=#AAAAAA]Restrict flat rendering to specific categories. Leave empty to apply to all.[/COLOR]
[*] [B][COLOR=#FFD700]rpg-drops.rotation-angle:[/COLOR][/B] [COLOR=#AAAAAA]Rotation in degrees (90.0 = perfectly flat on the ground).[/COLOR]
[*] [B][COLOR=#FFD700]rpg-drops.item-scale:[/COLOR][/B] [COLOR=#AAAAAA]Visual scale for individual item drops (default 0.6).[/COLOR]
[*] [B][COLOR=#FFD700]rpg-drops.block-scale:[/COLOR][/B] [COLOR=#AAAAAA]Visual scale for block drops (default 0.8). Allows different sizing per type.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Economy Support:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]economy.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Automatically detect money drops from other plugins using PDC tags.[/COLOR]
[*] [B][COLOR=#FFD700]economy.format:[/COLOR][/B] [COLOR=#AAAAAA]Hologram label format. Use [I]<prefix>[/I] and [I]<amount>[/I] as placeholders.[/COLOR]
[*] [B][COLOR=#FFD700]economy.prefix:[/COLOR][/B] [COLOR=#AAAAAA]Currency prefix displayed before the amount (e.g. &a$&f).[/COLOR]
[*] [B][COLOR=#FFD700]economy.color:[/COLOR][/B] [COLOR=#AAAAAA]Glow color of money drops (e.g. GOLD).[/COLOR]
[*] [B][COLOR=#FFD700]economy.sound:[/COLOR][/B] [COLOR=#AAAAAA]Sound played when a player walks near a money drop.[/COLOR]
[*] [B][COLOR=#FFD700]economy.custom-keys:[/COLOR][/B] [COLOR=#AAAAAA]Extra PDC keys to scan for currency amounts (format: namespace:key). Most common plugins are detected automatically.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Advanced Performance (LOD):[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]performance.lod.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Enable the Level of Detail system. Highly recommended for large servers.[/COLOR]
[*] [B][COLOR=#FFD700]performance.lod.hologram-distance:[/COLOR][/B] [COLOR=#AAAAAA]Holograms beyond this range are hidden (default 24 blocks).[/COLOR]
[*] [B][COLOR=#FFD700]performance.lod.beam-distance:[/COLOR][/B] [COLOR=#AAAAAA]Beams beyond this range are hidden (default 48 blocks).[/COLOR]
[*] [B][COLOR=#FFD700]performance.lod.particle-distance:[/COLOR][/B] [COLOR=#AAAAAA]Particles are skipped if no player is within this range (default 32 blocks).[/COLOR]
[*] [B][COLOR=#FFD700]performance.update-interval:[/COLOR][/B] [COLOR=#AAAAAA]Ticks between each LOD check cycle (default 20 = 1 second).[/COLOR]
[*] [B][COLOR=#FFD700]Zero-Entity Logic:[/COLOR][/B] [COLOR=#AAAAAA]All visual entities are invisible by default and only revealed to nearby players, minimizing server and client load.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Magnet Mode (VIP Perk):[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]magnet.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Enable the auto-pickup feature.[/COLOR]
[*] [B][COLOR=#FFD700]magnet.distance:[/COLOR][/B] [COLOR=#AAAAAA]Attraction range in blocks (default 5.0).[/COLOR]
[*] [B][COLOR=#FFD700]magnet.permission:[/COLOR][/B] [COLOR=#AAAAAA]Required permission node (default lootglow.magnet).[/COLOR]
[*] [B][COLOR=#FFD700]magnet.categories-enabled:[/COLOR][/B] [COLOR=#AAAAAA]List of rarity categories attracted by the magnet (e.g. legendary, epic, rare).[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Grouping & Visual Bags:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]grouping.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Consolidate nearby identical items into a single stack to reduce hologram clutter.[/COLOR]
[*] [B][COLOR=#FFD700]grouping.radius:[/COLOR][/B] [COLOR=#AAAAAA]Search radius in blocks to find items to group together (default 2.0).[/COLOR]
[*] [B][COLOR=#FFD700]grouping.min-items:[/COLOR][/B] [COLOR=#AAAAAA]Minimum number of items required to form a group (default 5).[/COLOR]
[*] [B][COLOR=#FFD700]grouping.group-by-category:[/COLOR][/B] [COLOR=#AAAAAA]If true, only items sharing the same rarity category are grouped together.[/COLOR]
[*] [B][COLOR=#FFD700]grouping.visual.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Show a visual Loot Bag entity instead of a plain item stack.[/COLOR]
[*] [B][COLOR=#FFD700]grouping.visual.material:[/COLOR][/B] [COLOR=#AAAAAA]Material used for the Loot Bag (e.g. PLAYER_HEAD, BUNDLE, CHEST).[/COLOR]
[*] [B][COLOR=#FFD700]grouping.visual.head-texture:[/COLOR][/B] [COLOR=#AAAAAA]Base64 skin texture for PLAYER_HEAD bags. Leave empty to use the default bag texture.[/COLOR]
[*] [B][COLOR=#FFD700]grouping.visual.use-owner-head:[/COLOR][/B] [COLOR=#AAAAAA]If true and material is PLAYER_HEAD, use the skin of the player who dropped the items.[/COLOR]
[*] [B][COLOR=#FFD700]grouping.visual.custom-model-data:[/COLOR][/B] [COLOR=#AAAAAA]Custom Model Data value for resource pack support (0 to disable).[/COLOR]
[*] [B][COLOR=#FFD700]grouping.container.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Enable the right-click GUI to browse the content of a Loot Bag.[/COLOR]
[*] [B][COLOR=#FFD700]grouping.container.title:[/COLOR][/B] [COLOR=#AAAAAA]Title of the Loot Bag GUI. Supports MiniMessage formatting.[/COLOR]
[*] [B][COLOR=#FFD700]grouping.container.require-click:[/COLOR][/B] [COLOR=#AAAAAA]If true, players must right-click to open the bag (walking over it won't open it).[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Farming Highlights:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]farming.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Display a floating '!' symbol above fully grown crops.[/COLOR]
[*] [B][COLOR=#FFD700]farming.glow-color:[/COLOR][/B] [COLOR=#AAAAAA]Color of the glow effect on the symbol (e.g. GREEN).[/COLOR]
[*] [B][COLOR=#FFD700]farming.symbol-material:[/COLOR][/B] [COLOR=#AAAAAA]Block used as the visual symbol (default EMERALD_BLOCK).[/COLOR]
[*] [B][COLOR=#FFD700]farming.symbol-scale:[/COLOR][/B] [COLOR=#AAAAAA]Size of the symbol display entity (default 0.2).[/COLOR]
[*] [B][COLOR=#FFD700]farming.height-offset:[/COLOR][/B] [COLOR=#AAAAAA]Vertical offset above the crop block (default 1.5).[/COLOR]
[*] [B][COLOR=#FFD700]farming.animation:[/COLOR][/B] [COLOR=#AAAAAA]Enable the gentle rotation and bobbing animation on the symbol.[/COLOR]
[*] [B][COLOR=#FFD700]farming.view-distance:[/COLOR][/B] [COLOR=#AAAAAA]Distance in blocks at which farming symbols become visible (default 5.0).[/COLOR]
[*] [B][COLOR=#FFD700]farming.crops:[/COLOR][/B] [COLOR=#AAAAAA]List of crop materials to monitor (WHEAT, CARROTS, POTATOES, BEETROOTS, NETHER_WART, COCOA...).[/COLOR]
[*] [B][COLOR=#FFD700]lootglow-farming flag (WorldGuard):[/COLOR][/B] [COLOR=#AAAAAA]Custom WorldGuard flag. Run [I]/rg flag <region> lootglow-farming deny[/I] to disable crop highlights in specific regions only.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Loot Protection:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]loot-protection.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Show the owner's name above their freshly dropped item.[/COLOR]
[*] [B][COLOR=#FFD700]loot-protection.display-duration:[/COLOR][/B] [COLOR=#AAAAAA]Seconds the owner label remains visible after the drop (default 10).[/COLOR]
[*] [B][COLOR=#FFD700]loot-protection.hard-lock:[/COLOR][/B] [COLOR=#AAAAAA]Physically prevent other players from picking up the item during the protection window.[/COLOR]
[*] [B][COLOR=#FFD700]loot-protection.bypass-permission:[/COLOR][/B] [COLOR=#AAAAAA]Permission node that lets admins bypass hard-lock protection (default lootglow.bypass.lock).[/COLOR]
[*] [B][COLOR=#FFD700]display-names (per category):[/COLOR][/B] [COLOR=#AAAAAA]Define custom MiniMessage names for specific items in a category (e.g. "DIAMOND" -> "<blue>Shiny Gem").[/COLOR]
[*] [B][COLOR=#FFD700]owner-format (messages.yml):[/COLOR][/B] [COLOR=#AAAAAA]Customize the owner line format. Supports <owner> placeholder and PlaceholderAPI.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]WorldGuard Support:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]worldguard.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Toggle WorldGuard integration.[/COLOR]
[*] [B][COLOR=#FFD700]worldguard.blocked-regions:[/COLOR][/B] [COLOR=#AAAAAA]List of region IDs where all LootGlow visuals are disabled.[/COLOR]
[*] [B][COLOR=#FFD700]lootglow-farming flag:[/COLOR][/B] [COLOR=#AAAAAA]Selectively control crop highlights per region. Independent from the general blocked-regions list.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Physics & Animations:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]spawn-animation.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Enable the "pop" effect when an item first appears.[/COLOR]
[*] [B][COLOR=#FFD700]spawn-animation.jump-force:[/COLOR][/B] [COLOR=#AAAAAA]Initial upward velocity of the pop effect (default 0.25).[/COLOR]
[*] [B][COLOR=#FFD700]spawn-animation.burst-amount:[/COLOR][/B] [COLOR=#AAAAAA]Number of particles in the spawn burst explosion (default 15).[/COLOR]
[*] [B][COLOR=#FFD700]spawn-animation.bouncing.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Items bounce realistically on the ground after landing.[/COLOR]
[*] [B][COLOR=#FFD700]spawn-animation.bouncing.max-bounces:[/COLOR][/B] [COLOR=#AAAAAA]Maximum number of bounces before the item comes to rest (default 3).[/COLOR]
[*] [B][COLOR=#FFD700]spawn-animation.bouncing.damping:[/COLOR][/B] [COLOR=#AAAAAA]Energy retained after each bounce (0.0 to 1.0). Lower = faster stop (default 0.6).[/COLOR]
[*] [B][COLOR=#FFD700]aspiration.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Items fly smoothly toward the player's inventory when picked up.[/COLOR]
[*] [B][COLOR=#FFD700]aspiration.speed:[/COLOR][/B] [COLOR=#AAAAAA]Speed of the fly-to-player animation (0.1 to 0.5 recommended, default 0.15).[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Visual Beams:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]beams.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Toggle the vertical light pillar above high-rarity loot.[/COLOR]
[*] [B][COLOR=#FFD700]beams.height:[/COLOR][/B] [COLOR=#AAAAAA]Height of the beam in blocks (default 10).[/COLOR]
[*] [B][COLOR=#FFD700]beams.width:[/COLOR][/B] [COLOR=#AAAAAA]Width (thickness) of the beam. Default 0.05 for a thin line.[/COLOR]
[*] [B][COLOR=#FFD700]beams.animate:[/COLOR][/B] [COLOR=#AAAAAA]Enable rotation animation for a "living" beam effect.[/COLOR]
[*] [B][COLOR=#FFD700]beams.use-category-color:[/COLOR][/B] [COLOR=#AAAAAA]The beam glass color matches the item's rarity color.[/COLOR]
[*] [B][COLOR=#FFD700]beams.enabled-categories:[/COLOR][/B] [COLOR=#AAAAAA]Which rarity categories trigger a beam (e.g. legendary, epic).[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Particles:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]particles.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Toggle ambient particles around categorized items.[/COLOR]
[*] [B][COLOR=#FFD700]particles.frequency:[/COLOR][/B] [COLOR=#AAAAAA]Ticks between each particle burst (default 10). Higher = less frequent.[/COLOR]
[*] [B][COLOR=#FFD700]particles.animation-type:[/COLOR][/B] [COLOR=#AAAAAA]Global fallback animation style for particles (e.g. STILL). Overridden by category-specific settings.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Right-Click Pickup (Interaction):[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]interaction.rmb-pickup.enabled:[/COLOR][/B] [COLOR=#AAAAAA]Allow players to right-click an item or its hologram to pick it up.[/COLOR]
[*] [B][COLOR=#FFD700]interaction.rmb-pickup.force:[/COLOR][/B] [COLOR=#AAAAAA]If true, right-clicking is the ONLY way to pick up items (walking over them is disabled).[/COLOR]
[*] [B][COLOR=#FFD700]interaction.rmb-pickup.range:[/COLOR][/B] [COLOR=#AAAAAA]Maximum distance for right-click pickup (default 3.0 blocks).[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Custom Items & Integrations:[/COLOR][/B]

[*] [B][COLOR=#FFD700]MYTHIC:id[/COLOR][/B] [COLOR=#AAAAAA]— Matches a MythicMobs item OR mob drop by its internal name.[/COLOR]
[*] [B][COLOR=#FFD700]MMOITEMS:type:id[/COLOR][/B] [COLOR=#AAAAAA]— Matches an MMOItems entry by type and ID.[/COLOR]
[*] [B][COLOR=#FFD700]ECOITEMS:itemID[/COLOR][/B] [COLOR=#AAAAAA]— Matches an EcoItems item by its ID.[/COLOR]
[*] [B][COLOR=#FFD700]ADVANCEDITEMS:itemID[/COLOR][/B] [COLOR=#AAAAAA]— Matches an AdvancedItems item by its ID.[/COLOR]
[*] [B][COLOR=#FFD700]ITEMEDIT:itemID[/COLOR][/B] [COLOR=#AAAAAA]— Matches an ItemEdit item by its ID.[/COLOR]
[/LIST]

[SIZE=5][B][COLOR=#FFD700]💬  3. LOCALIZATION (messages.yml)[/COLOR][/B][/SIZE]
[COLOR=#888888]────────────────────────────────────────────────────[/COLOR]
[COLOR=#D3D3D3]LootGlow supports full [B]MiniMessage[/B] formatting in [B]messages.yml[/B]. Use the [B]<prefix>[/B] placeholder to keep your messages consistent:[/COLOR]

[SIZE=3] [/SIZE]

[CODE=yaml]
prefix: "<gradient:#FFD700:#FFFFFF><bold>[LootGlow]</bold></gradient> <gray>» </gray>"

no-permission: "<prefix><red>You don't have permission to do this!</red>"
config-reloaded: "<prefix><green>Configuration and messages successfully reloaded!</green>"

plugin-info:
  - "<gradient:gold:white><bold>LootGlow</bold></gradient> <gray>v<version>"
  - "<gray>Author: <white><author>"
  - "<gray>Use <yellow>/lg help</yellow> to see commands."

help-header: "<gold>--- <yellow>LootGlow Help</yellow> ---</gold>"
help-reload: "<yellow>/lg reload <gray>- <white>Reload the plugin configuration"
help-toggle: "<yellow>/lg toggle <gray>- <white>Toggle item visuals for yourself"
help-magnet: "<yellow>/lg magnet <gray>- <white>Toggle item magnet for yourself"

toggle-on: "<prefix><green>Item visuals have been enabled for you.</green>"
toggle-off: "<prefix><red>Item visuals have been disabled for you.</red>"

magnet-on: "<prefix><green>Item magnet has been enabled for you.</green>"
magnet-off: "<prefix><red>Item magnet has been disabled for you.</red>"

# Hologram Format — use <amount> and <time> as placeholders
item-amount-format: " <gray>(x<amount>)</gray>"
item-timer-format: " <gray>(<time>s)</gray>"

# Loot Protection — use <owner> for the player's name (PlaceholderAPI supported)
owner-format: "<newline><gray>Owned by</gray> <white><owner></white>"

# Announcements
legendary-found: "<prefix><gradient:#FFD700:#FFAA00><bold>LEGENDARY!</bold></gradient> <white>A precious item has been discovered nearby!</white>"

# Pickup Protection — use <owner> and <time>
cannot-pickup: "<prefix><red>This item belongs to <white><owner></white>! Try again in <white><time>s</white>.</red>"
[/CODE]

[SIZE=5][B][COLOR=#FFD700]🛠️  4. COMMANDS[/COLOR][/B][/SIZE]
[COLOR=#888888]────────────────────────────────────────────────────[/COLOR]
[COLOR=#AAAAAA]The main command is [B]/lootglow[/B] with aliases [B]/lg[/B] and [B]/glow[/B].[/COLOR]

[TABLE]
[TR]
[TD][B][COLOR=#FFD700]/lg[/COLOR][/B][/TD]
[TD][COLOR=#AAAAAA]Display plugin information and version.[/COLOR][/TD]
[/TR]
[TR]
[TD][B][COLOR=#FFD700]/lg help[/COLOR][/B][/TD]
[TD][COLOR=#AAAAAA]List all available commands.[/COLOR][/TD]
[/TR]
[TR]
[TD][B][COLOR=#FFD700]/lg toggle[/COLOR][/B][/TD]
[TD][COLOR=#AAAAAA]Hide or show item visuals for yourself.[/COLOR][/TD]
[/TR]
[TR]
[TD][B][COLOR=#FFD700]/lg magnet[/COLOR][/B][/TD]
[TD][COLOR=#AAAAAA]Toggle your personal item magnet on or off.[/COLOR][/TD]
[/TR]
[TR]
[TD][B][COLOR=#FFD700]/lg reload[/COLOR][/B][/TD]
[TD][COLOR=#AAAAAA]Reload config.yml and messages.yml. Requires [I]lootglow.admin[/I].[/COLOR][/TD]
[/TR]
[/TABLE]
